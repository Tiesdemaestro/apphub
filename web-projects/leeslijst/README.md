# Mijn leeslijst

Houd boeken bij met auteur, leesnotities en de status te lezen, bezig of uitgelezen.

Voeg https://tiesdemaestro.github.io/apphub/leeslijst/ toe via Project toevoegen in AppHub. Deze mini-app gebruikt eigen IndexedDB-opslag, zonder account of backend. De browseropslag van de simulator kan aan het einde van een sessie worden gewist. Exporteer gegevens om ze mee te nemen.

Tests: node --test web-projects/leeslijst/domain.test.mjs
Audit: node scripts/check-web-project.mjs web-projects/leeslijst --json

Technische compatibiliteit is geen Apple-goedkeuring; toesteltests blijven nodig.
